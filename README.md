Sistema Elos – Elos de Inclusão
Sistema web desenvolvido como Progressive Web App (PWA) com o objetivo de conectar pais de crianças PCD (Pessoas com Deficiência) a acompanhantes/tutores, facilitando o acompanhamento diário e a comunicação em tempo real.
🚀 Funcionalidades
📍 Localização em tempo real do acompanhante
💬 Chat em tempo real entre pais e tutores
👤 Cadastro e gerenciamento de usuários (pais e acompanhantes)
🤝 Escolha personalizada de acompanhantes
📝 Registro de ocorrências
Medicamentos administrados
Relatos de eventos (crises, comportamentos, etc.)
📱 PWA (Progressive Web App)
Pode ser instalado no celular
Funciona com cache e suporte offline parcial
🎯 Objetivo
O Sistema Elos foi idealizado como um projeto social para melhorar a comunicação, segurança e confiança entre pais e acompanhantes de crianças que necessitam de atenção especial, especialmente no ambiente escolar.

⚙️ Como Executar o Projeto
Clone o repositório:
Bash
git clone <URL_DO_REPOSITORIO>
Acesse a pasta:
Bash
cd nome-do-projeto
Instale as dependências:
Bash
npm install
Execute o servidor:
Bash
npm start
Acesse no navegador:

http://localhost:3000
📲 Instalação como App (PWA)
Acesse o sistema pelo navegador no celular
Clique em “Adicionar à tela inicial”
O sistema funcionará como um aplicativo nativo
